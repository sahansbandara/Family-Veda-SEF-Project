The operating rules for every coding agent in this repository live in [`AGENTS.md`](AGENTS.md). Read it in full before any task and follow it exactly.

Two rules are restated here because they are the ones most often missed:

- **UI parity rule** — any UI change is applied to web desktop, web mobile and the Flutter app in the same change, and reported with the completion table in `AGENTS.md`. This applies automatically; the user does not have to ask.
- **Clinical safety rules** — see `CLAUDE.md`. Any change that breaks one is rejected regardless of who asked for it.
